💎 GemFetch

Save a Google AI answer as a clean Markdown note — in one click.

Get the extension View source

What it does

  • Reads the AI Overview box or AI Mode conversation on a Google search page.
  • Uses the Gemini API (your own free key) to write a title, a bullet-point synthesis, and a tidy transcript — stripping buttons, follow-up chips, disclaimers and filler.
  • Writes it to a folder you choose as YYMMDD-title.md, with the source link inside.
  • Optional: file each note into a subfolder named after the current Chrome tab group, and move notes into an Archive.

Private by design

Your API key and settings never leave your browser. The only network request is the summarization call to Google, made with your key. No analytics, no servers, no tracking. Full privacy policy →

Install

Until it's on the Chrome Web Store, load it unpacked:

  1. Download or clone the repository.
  2. Open chrome://extensions and turn on Developer mode.
  3. Load unpacked → pick the gemfetch folder.
  4. Open the extension's options: paste a free Google AI Studio API key, click Refresh to pick a model, and choose your working folder.
  5. Pin the icon. On any Google search with AI Mode / AI Overview, click it.

Notes

  • The free Gemini tier is rate-limited per day. Heavy users can enable billing on their own key (a consumer "Gemini" subscription does not raise API limits).
  • Google's markup shifts often; if the scrape misses content, select the answer text on the page first, then click.
