GemFetch — Privacy Policy

Last updated: 2026-08-30

GemFetch is a browser extension that saves a Google AI Overview / AI Mode answer as a Markdown file on your computer.

What GemFetch handles

  • Page content — when you click the toolbar button, GemFetch reads the text of the Google results page you are on, to extract the answer.
  • Your API key — a Google AI Studio key you enter in settings.
  • Your settings — model, working-folder name/path, group names, extra instructions, and a short list of recent saves.

Where it goes

  • Stays on your device: API key, settings, recent-saves list (chrome.storage.local), folder handle (IndexedDB). Never sent to the author or any third party.
  • Sent to Google: the scraped page text and your query go to generativelanguage.googleapis.com using your key, only to generate the title, synthesis and transcript. Governed by Google's API terms.
  • Written to disk: the Markdown file goes only to the folder you selected.

What GemFetch does not do

  • No analytics, telemetry, tracking or advertising.
  • No remote code loading.
  • No developer-operated servers — there is no backend.
  • No access to browsing history, other tabs, cookies or passwords.
